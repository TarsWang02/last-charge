# 卧室画面优化 · 2026-10-03

完成床头柜、床铺、纸箱与书桌的灯光、材质和镜头调整，目标是保留夜间的私密感，同时显出圆润旧玩具与微缩摄影的质感。

## 主要变化

- 月光聚光能量由 40 降到 3.4，扩大并柔化光束，消除床头柜和主角的大面积过曝。
- 降低蓝色偏色与后期饱和度，以中性冷光衔接温暖台灯；新增 5 处有限范围的低强度补光，帮助读出床品、人物与纸箱内的平台层次。
- 窗玻璃增加粗糙度并降低镜面反射，消除夸张白色光斑；辅助灯不产生镜面高光。
- 减轻普通雾和体积雾，降低辉光、色散、暗角和颗粒。缩小移轴模糊强度，扩大清晰区域；卧室启用 4× MSAA。
- 初始镜头俯角由 14° 调至 19°，让主角、桌面与前方机关的关系更清楚。
- 保留低电量失色、闪烁与暗角变化。书桌俯视时关闭新增补光及移轴模糊；离开卧室后还原环境、后期和抗锯齿设置。

## 验证

- 状态检查全部通过：低电量驱动、迷宫熄灯、补光关闭/恢复、外部区域渲染还原。
- 平台尺寸、原碰撞几何、51 个美术实例及机关回归全部通过。
- 种子 7 图形模式完整路线通过，route_respawns=0、walk_stalls=[]；运行错误日志为空。
- 画面使用真实游戏灯光和后期采集，没有为了截图额外提亮环境。
