# 停电卧室氛围修订

用户反馈上一版整体过亮，要求带奇幻色彩的停电房间、强烈明暗对比、大量灰尘，以及光在黑暗中晕染的感觉。本版以此为美术方向。

- 降低环境色与方向光贡献，让背景和大面积家具退入暗处；只有月光、暖灯、主角及互动机关形成局部亮区。
- 月光聚光能量调至 8（最初白模版为 40），光束收窄为 20°，体积散射贡献增加至 5；普通雾密度 .004，体积雾 .012。
- 增加辉光、冷暖分色与适量暗角，保留表面细节，同时使光源边缘柔和晕开。
- 光束周围添加共 170 个缓慢漂移的微小浮尘粒子，月光区域偏冷、台灯区域偏暖。不是全屏颗粒蒙版。
- 大幅削弱广泛补光，仅保留纸箱边缘和落脚点的少量轮廓提示；原碰撞和平台位置未修改。
- 书桌迷宫中关闭新增补光、浮尘和移轴模糊；低电量效果及离开卧室后的渲染恢复检查通过。
