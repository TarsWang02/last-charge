## 风格与导出

- 普通道具避免青色/蓝绿色；低饱和、圆润厚实、旧玩具和微缩场景感。
- 颜色贴图不画光影、不烘焙 AO。继续沿用前几批关闭 PBR 生成的设置；粗糙度和必要的材质参数由我在 Blender/Godot 中处理。
- 建议导出带颜色贴图的 GLB。人物约 8k–12k 三角形，床品约 5k–8k，娃娃头约 3k；最终会按游戏表现优化。
- 不做绑定和人物动画；静态摆姿即可。
- 把四个返回模型放到桌面并告诉我，我会接着拟合、入库和替换对应白模。
