# bear

单只熊与兔子组装。整堆落点直径约0.30m，站立面顶高0.12m。左膝芥末黄补丁；配色和兔子同系列。500–3000三角面，512–1024贴图。

## Tripo 补充要求

只生成图中的单件物品；四视图展示同一个物品，不生成四份。风格化圆润旧玩具，手绘固有色磨损；不要烤光影、AO、高光、暗角。普通道具不用青色；GLB贴图内嵌，真实米，Y朝上，正面+Z。图中的照明不能转为贴图阴影。参考图不是尺寸证明，模型返回后由Blender校正。

## 四视图修正要求

前/后/左/右，单一物品，纯白底，保持造型和姿势一致，移除场景和其他玩具，减少写实材质细节。
