# 卧室与纸箱：节约 Tripo 额度的素材分工

全项目预算：30 次高质量模型生成。本阶段建议首次生成仅 5 个；保留 25 次供失败重做和后续关卡。参考图生成不消耗 Tripo 模型额度；本次未操作 Tripo 或消耗其额度。

## Blender 制作清单

- 卧室：地板/墙材质、窗框和玻璃、床架与床品、侧睡老人可见部分、书桌、台灯、椅子与背景坐姿少年。
- 床头柜：床头柜、旧书堆、两种药瓶、水杯、老花镜、共用硬币、悬空精装书、相框。
- 纸箱：纸箱与盖板、积木堆、卡车、环形轨道与火车车厢、玩偶匣盒身与摇柄、小丑弹簧、两种瓷娃娃头、鞋盒、A/B 字母积木、小车、鼓、尺子、支点与落点支撑积木、电池；大机器人眼睛和猴子可动部件后处理。
- 全家福是二维素材；音频单独处理，不占模型额度。
- 人物、布料先制作与镜头距离相符的简化版本；本阶段不预先占用 Tripo 额度。如果镜头表现确实不够，再由用户选择是否追加。

## 统一风格

主角来源：assets/models/robot_parts_v2.glb；项目实机参考：shots/robot_diorama_parts_front34.png。
圆润厚实的旧玩具/微缩模型；芥末黄、炭灰、褪色砖红、旧象牙白、褪色棕布。磨损以固有色变化、克制的掉漆和补丁表达。贴图无光影、AO、高光、暗角；引擎负责打光。普通道具不用高饱和青色。大机器人眼睛为琥珀色，单独节点；青色交互提示由引擎叠加。

## 首批 Blender 交付

prop_seesaw_ruler.glb、prop_seesaw_fulcrum.glb、prop_seesaw_rest.glb、prop_drum.glb、prop_electric_car.glb。
纹理内嵌 512px；真实米；glTF Y 向上，小车正面 +Z。尺子底面中点枢轴，鼓中心枢轴，小车底面中心枢轴。
源文件 exit_props_source.blend；脚本 build_exit_props.py；实际包围盒及面数见 exit_props_metrics.json。

尺子：0.36×0.08×0.014m。鼓：直径0.12m，高0.09m。小车：0.08m长×0.05m宽×0.03m高。支点：0.06×0.10×0.06m。低端支撑：0.04×0.06×0.03m。
鼓采用文档的总高9cm；白模另叠加鼓皮，使外观略高，替换时保留原碰撞和动作逻辑。
悬空书枢轴存在文档/脚本差异，后续以可独立视觉模型配合现有桌沿父节点的方式保留玩法。

不自动入库或替换场景。小道具高度小于5cm会触发现有通用检查的高度 WARN；这是预期真实尺寸，不应为消除 WARN 而放大。
