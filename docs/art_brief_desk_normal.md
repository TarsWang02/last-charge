# 3D 美术需求：第 2 站 · 熄灯前的"正常书桌"

> **交给 GPT / Codex 执行。**本文件只描述需要什么模型、放在哪里、要满足什么条件。玩法代码已经写好，**不要改**（`scripts/room.gd`、`scripts/desk_maze*.gd`、`tools/gen_room.py`）。
> 风格、颜色规则、格式和入库流程：沿用 `docs/art_audio_brief_bedroom_toybox.md` 第 2、3、6 节。
> **改代码前先 `git pull`，或重新读取最新文件，只做局部修改，不要整个文件覆盖。**

## 1. 这是什么

机器人被跷跷板弹上书桌。落地后**台灯还亮着**，镜头切成机器人自己的眼睛：
1. 看向坐在桌前写作业的少年。那是十五岁的他。
2. 视线沿着桌面移到最远处的门把手。
3. 台灯熄灭，屋里一片漆黑。
4. 灯一黑，**同一张桌子变成了乱糟糟的迷宫**：墙、杂物、桌缝、橡皮、妈妈的纸条。

现在第 4 步之前，迷宫整个是隐藏的（`Stop2/DeskMaze` 不可见），桌面上几乎是空的，看起来很假。**需要一套熄灯前的"正常书桌"摆设**：一个十五岁少年正在写作业的桌面，乱，但是是正常的乱。

**一句话**：灯亮时，这是一张普通的、有人正在用的书桌；灯一黑，它变成迷宫。两者要像是同一张桌子：同样的书、同样的铅笔盒、同样的颜色，只是黑暗里的东西被放大、被堆成了墙。

## 2. 接入方式（已预留）

- 新建节点 **`Stop2/DeskNormal`**（`Node3D`），所有"正常书桌"的模型都放在它下面。建议写一个 `scripts/desk_normal_art.gd`，在 `scripts/room_art.gd` 里注册，做法和其他 `*_art.gd` 一样。
- **台灯熄灭、迷宫出现的那一刻，`room.gd` 会自动把 `Stop2/DeskNormal` 隐藏。**这一段已经写好，不用改。
- `DeskNormal` 下的东西**都不要碰撞**（不加 `CollisionShape3D`、不开 `use_collision`）。熄灯前机器人被锁着不能动，碰撞没有意义，还可能和迷宫的碰撞打架。

## 3. 位置和硬约束

坐标是真实米制，在引擎里要乘以 9。

- **桌面范围**：x -1.16 到 -0.46，z -0.55 到 0.85，**桌面高 0.75**。桌子东边靠着卧室东墙。
- **台灯**：在东墙上，灯罩位置约 (-0.54, 1.10, 0.55)，已经有了，不用做。
- **少年**：`prop_seated_teen` 已经有了，坐在桌子西侧（x -1.67 到 -1.08，z 0.28 到 0.71），面朝东。**他的作业应该摊在他面前**，大约 x -1.15 到 -0.85，z 0.30 到 0.70。
- **机器人落点**在 (-1.10, 0.752, -0.49)，桌子的西北角。**以这里为中心，半径 12 cm 内不要放东西。**
- **两条视线不能被挡**，第一人称镜头的眼睛在 (-1.10, 0.84, -0.49)：
  - 看向少年的脸 (-1.36, 1.16, 0.50)；
  - 沿桌面看向门把手 (-0.45, 0.85, 0.95)。

  这两条视线经过的桌面上，**东西不能高过 8 cm**。高的东西（书立、笔筒、台历）放在桌子东侧靠墙的位置，或者桌子南端的角落。
- 面数：每件 300–3,000 三角面，整套加起来不超过 25,000。贴图 256–512。
- 不能出现真实品牌、商标或可读的文字（作业本上的字只用横线和涂鸦表示）。

## 4. 摆设清单（建议，可以增减）

| 名字 | 放在哪 | 说明 |
|---|---|---|
| `desk_n_homework` | 少年面前 | 摊开的数学练习本（只画格线和铅笔涂写的痕迹）、一支削过的铅笔、一块橡皮。**这块橡皮要和迷宫里那块一模一样**，迷宫里那块是同一个东西被放大了。 |
| `desk_n_textbooks` | 桌子东侧靠墙 | 一摞课本加一个书立，最高 18 cm。可以复用迷宫里书本墙的颜色。 |
| `desk_n_pencil_case` | 作业本旁边 | 铅笔盒，和迷宫里的一致。 |
| `desk_n_ruler_protractor` | 桌子中部 | 一把尺子、一个量角器，平放。 |
| `desk_n_mug` | 桌子东南角 | 一杯放凉了的茶或阿华田，杯口有个小勺。 |
| `desk_n_mum_note` | 桌子南端，靠近门那头 | **妈妈的纸条**，对折后立着，像是压在什么东西下面。贴图复用 `prop_desk_folded_note_mom_note_colour.png`。迷宫里那张纸条也在南端，熄灯后就是它。**不要做发光**，引擎会负责。 |
| `desk_n_clutter` | 零散 | 几张草稿纸、一支圆规、一块糖纸、一个小闹钟。少年房间的正常杂乱。 |
| `desk_n_radio`（可选） | 桌子东北角靠墙 | 一台小收音机。 |

**颜色**：灯亮时整体是暖黄的台灯光。贴图只画固有色，**不要烤进光影**。不要用高饱和的青色，青色只给能互动的东西。

## 5. 验收（必须实际运行，不许编造结果）

1. 入库：先跑 `tools/slim_glb.py`，再跑 `tools/inbox.py check`，不能有 FAIL。
2. 跑完整自测，看书桌这一段：

   ```
   D:\Godot_v4.7.2-stable_win64_console.exe --path . res://scenes/room.tscn -- --autotest --desk-autotest --shots=shots/desk_normal
   ```

   - `stop2` 里 `desk_first_person`、`top_down`、`room_dark`、`reached_goal_cell` 必须是 `true`。
   - 截图 `room_s2_pov_boy.png` 是第一人称看向少年的那一帧，要能看清作业摊在他面前，**视线没有被东西挡住**。
   - 截图 `room_s2_dark.png` 是熄灯后，要确认正常书桌已经消失，只剩迷宫。
   - 注意：现在 `stop2` 里的 `note_found` 会是 `false`。纸条已经改成要按 E 阅读，自测脚本不会按，这是已知问题，不用管。
3. 导出后核对 exe 的修改时间晚于导出开始时间。
4. 报告写在 `docs/art_production_<日期>/desk_normal/REPORT.md`，内容包括：做了哪些件、自测结果、截图路径。没测的写"未测"。
