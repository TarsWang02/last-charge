# 全屋美术统一 — 2026-10-04

以第一节卧室的停电夜景、微缩玩具摄影和柔和卡通材质为基准。

## 渲染与光照
- 修正出卧室后恢复旧后处理的问题：全屋沿用卧室 ACES、4×MSAA、轻景深、低颗粒和轻色散。保留游戏控制的低电量、环境光强度、断电与结尾亮灯变化。
- 统一客厅、厨房、滑索、配电箱和各年龄人物的漫反射与法线强度，减少布料、皮肤和木头的塑料高光；透明、发光、引擎自定义材质保留用途，豆豆瓷摆件保留釉面。
- 开放客厅比封闭卧室接收更多天光，门口颜色平滑过渡。电视冷光、炉火暖光各自集中；南窗、积水边与配电箱有少量月光反射，避免全屋平铺亮光。
- 配电箱故障光收窄，减少大面积红墙。电视附近浮尘随屏幕关闭，炉火处浮尘随火源，窗边漂浮细尘延续卧室空气感。
- 积水降低金属感、镜面强度并提高粗糙度，消除恢复供电后突出的白色高光斑。

## 模型与穿模
- 厨师向南调整12cm：鞋与裤腿退出炉灶柜体。
- 沙发青年向北调整18cm：下半身退出坐垫内部；同步修改手柄连接线的前三段。
- 扶手椅老人向北调整18cm；Blender局部整理衣摆151个顶点，让衣摆落在椅面上，保持脚底与头顶高度。
- 三处重点实体内部采样：厨师270→0，青年439→0，老人437→0。此项是指定柜体/坐垫核心区域的顶点检查，不代表全场景任意运动状态均已验证。
