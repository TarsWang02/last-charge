# Audio credits — Last Charge

All music and almost all sound effects were generated procedurally with code written with AI assistance (Claude) for ANU CSSA Game Jam 2026.

- **Music**: original composition (except the desk-maze horror loop, credited below), rendered with FluidSynth using the **FluidR3_GM** SoundFont by Frank Wen (MIT License).
- **8-bit music, sound effects and ambience**: synthesised from scratch in Python (NumPy / SciPy). The only third-party recordings are the frog, rain, thunder, garage-door and plush 'honk' clips listed below.
- **Radio broadcast voice**: generated with **Piper TTS** (Rhasspy) using the *en-gb-alan-low* voice, which is trained on the Mycroft mimic3 "apope" dataset. Please check that dataset's licence before publishing: https://github.com/MycroftAI/mimic3-voices
- **Frog recordings** (rain frogs and all night frog layers): clips from the ESC-50 dataset by Karol J. Piczak (https://github.com/karolpiczak/ESC-50), originally from Freesound, used under CC BY 3.0 (edited: mixed, filtered, pitch-varied):
