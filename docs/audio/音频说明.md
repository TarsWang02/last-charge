# Last Charge 音频包

全部为 OGG Vorbis，44.1 kHz 立体声。音乐响度约 -16～-18 LUFS，音效峰值 -1～-3 dBFS（8-bit 音效和环境声更低）。
文件名带 `_循环` 的都已处理成无缝循环，导入 Godot 后在 Import 面板勾选 **Loop** 再点 Reimport。

## 窗外环境声（夜晚，随人生阶段变化）

全部是夜晚的声音。按策划书“乡村衰落”的暗线，越往后窗外越安静。四条整段混音可以直接用，每条约 38.5 秒：

| 青年 | 第 3 站 | `阶段混音2_青年_窗外_循环` | 蛙鸣，夜里驶过的汽车，一声狗叫，猫头鹰 |
| 中年 | 第 4 站 | `阶段混音3_中年_窗外_循环` | 蛙鸣变稀，远处狗叫，一辆车驶离小镇，风变大 |
| 老年 | 第 5 站窗台 | `阶段混音4_老年_窗外_循环` | 只剩风、零星蛙鸣和猫头鹰 |

单独素材：`全程_远处蛙鸣_循环`（远处蛙鸣）、`窗外_猫头鹰_01~02`（猫头鹰）、`窗外_喜鹊鸣唱_01~03`（喜鹊夜鸣）、`窗外_远处羊叫_01~02`、`窗外_远处牛叫_01~02`、`窗外_远处狗叫_01~02`、`窗外_远处汽车驶过`、`窗外_汽车驶离小镇`。

## 夜晚随机事件：醉汉和邻居

让环境声不那么单调，建议**很稀疏地随机触发**，每 1～3 分钟最多一次，不要放进循环里：

- `夜晚事件_醉汉被骂完整版_01~02`：完整的一段，约 15 秒。醉汉在街上含糊地自言自语，邻居开窗大喊让他闭嘴，“砰”地关窗（第 1 段后面还有一声狗叫），醉汉嘟囔一句“好啦好啦”走开。
- 也可以拆开用：`夜晚事件_醉汉碎碎念_01~03`（醉汉碎碎念）、`夜晚事件_邻居喊闭嘴_01~02`（邻居喊“Oi! Shut up! It's two in the morning!”这类话）。

醉汉的台词是含糊的英文（“Where's me keys...”“She'll be right, mate...”），用 TTS 生成。醉态全靠放慢语速和不规则的停顿来表现，不改变音调；再加上远处街道的低通和混响。喊闭嘴的邻居用女声，两个人容易分清。

```gdscript
# 随机夜晚事件：挂一个 Timer
func _on_night_event_timer_timeout() -> void:
    $NightEvent.stream = [preload("res://audio/环境声/夜晚事件_醉汉被骂完整版_01.ogg"),
                          preload("res://audio/环境声/夜晚事件_醉汉被骂完整版_02.ogg")].pick_random()
    $NightEvent.play()
    $NightEventTimer.start(randf_range(60.0, 180.0))
```

## 雨夜背景（为雨天场景准备）

## 终章对齐（终章_灌电.ogg，47.4 s）

| 事件 | 时间 |
|---|---|
| 乐句 1（照片）开始 | 2.25 s |
| 乐句 2（纸条）开始 | 11.25 s |
| 乐句 3（答录机）开始 | 20.25 s |
| 乐句 4（八音盒）开始 | 29.25 s |
| **最后一个音（最后一格电熄灭）** | **39.38 s** |
| 余音结束 | 47.4 s |

建议做法：**音乐只在按住 E 时播放，松开就暂停**。灌电进度直接用播放位置计算，这样最后一格电熄灭一定落在最后一个音上。时间点也保存在 `music_info.json` 里。

## Godot 接入示例

```gdscript
# audio_manager.gd（Autoload）
extends Node

const FINALE_LAST_NOTE := 39.38
var music := AudioStreamPlayer.new()
var finale := AudioStreamPlayer.new()
var low_power_fx := true   # 结局时设为 false

func _ready() -> void:
    add_child(music); add_child(finale)
    music.stream = preload("res://audio/音乐/主旋律_探索_循环.ogg")
    finale.stream = preload("res://audio/音乐/终章_灌电.ogg")
    music.play()

# power: 0.0 ~ 1.0。按关卡文档，50% 以下开始变慢变轻，到 15% 时最慢。
func set_power(power: float) -> void:
    if not low_power_fx:
        music.pitch_scale = 1.0; music.volume_db = 0.0; return
    var k := clampf((0.5 - power) / 0.35, 0.0, 1.0)
    music.pitch_scale = lerpf(1.0, 0.85, k)
    music.volume_db = lerpf(0.0, -8.0, k)

# 终章：每帧调用，返回灌电进度 0~1
func update_charge(holding: bool) -> float:
    if holding:
        if not finale.playing:
            music.stop(); finale.play()
        finale.stream_paused = false
    else:
        finale.stream_paused = true
    return clampf(finale.get_playback_position() / FINALE_LAST_NOTE, 0.0, 1.0)
```

- 旧物片段（旋律片段1~4）播放时，把 `music` 音量临时压低约 10 dB，结束后恢复。
- 循环音效用一个 AudioStreamPlayer3D 挂在对应物体上，3D 衰减就能实现“用声音远近带路”。
- 走路的 `机器人_履带行进_循环` 可以把 `pitch_scale` 和电量绑定，低电量时 0.8，听起来像马达没劲。
- 8-bit 音效偏响，已经整体压低；如果还是盖过音乐，在 Godot 里再降 3～6 dB。

## 重新生成

源代码在 `src/`：`music.py`（音乐）、`sfx.py`（音效和环境声）、`radio.py`（广播），依赖 FluidSynth、FluidR3_GM 音色库、ffmpeg 和 Piper TTS。
改旋律只需要编辑 `common.py` 里的 `PHRASES` 和 `PHRASE_CHORDS`，然后运行 `python3 music.py`。

## 文件名说明

- 所有文件已改为中文名，按“站点_内容”命名；`文件名对照表.csv` 列出了每个文件对应的原英文名。
- Godot 4 支持中文路径，但如果有人用 Windows + Git 遇到乱码，或者导出 Web 版时出问题，可以按对照表换回英文名，内容完全一样。
- “给自己充电”的两个音效模仿手机插上充电器时“咔、叮叮”的感觉，为原创合成，不是苹果的原版提示音。`给机关充电_循环` 和 `给机关充电_渐强10秒` 用于给电器、配电箱供电。
